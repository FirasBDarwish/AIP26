# Installation Instructions

## Option 1: Google Colab (Python) Installation Instructions
Colab is a hosted Jupyter Notebook service that requires no setup to use and provides free access to computing resources, including GPUs and TPUs. 

- NB: Google Colab will only work while you have an active internet connection, and you will need a valid Google account to use it.
- Visit https://colab.google/
- Click on “New Notebook”
- If you are not signed in to your Google account at this point, you will be prompted to either login or make an account.
- Start Coding!
- Your notebooks will be saved in your Google Drive in the folder “Colab Notebooks”:

## Option 2: Anaconda (Python) Installation Instructions
Anaconda is a distribution of the Python and R programming languages for scientific computing that aims to simplify package management and deployment. The distribution includes data-science packages suitable for Windows, Linux, and macOS.

- Visit https://www.anaconda.com/products/distribution
- Click Download
- Follow instructions to install the Anaconda Navigator
- Launch the Anaconda Navigator
- Install Jupyter Notebooks
- Click Launch to open a notebook
